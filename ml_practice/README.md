# Практика регрессии

`regression_baseline.py` сравнивает два способа прогнозировать числовой показатель:
среднее значение обучающей выборки и Ridge-регрессию с заранее заданным `alpha=1`.
Используется встроенный Diabetes: 442 объекта, 10 признаков. Цель — показатель
прогрессирования заболевания из набора данных; это учебный пример, не медицинский
инструмент. MAE и RMSE выражены в единицах этого показателя, R² безразмерен.

Из корня репозитория на Mac:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r ml_practice/requirements.txt
python ml_practice/regression_baseline.py
python -m unittest discover -s ml_practice -v
```

Чтобы сохранить собственный отчёт в отдельный файл:

```bash
python ml_practice/regression_baseline.py --output /tmp/regression_report.json
```

80% объектов идут в train, 20% — в test; seed по умолчанию 42. Пять разбиений
кросс-валидации создаются только внутри train. Исходные признаки загружаются без
предварительного масштабирования. StandardScaler находится внутри Pipeline,
поэтому подгоняется заново на обучающей части каждого CV-разбиения.
В итоговой модели он обучается на всём train. Test при этом не используется.

`cv_mae_mean` — средняя MAE по пяти проверочным частям train, `cv_mae_std` —
стандартное отклонение этих пяти оценок, не доверительный интервал.
`test_mae`, `test_rmse`, `test_r2` — итоговые метрики одного отложенного набора.
Отрицательный R² возможен: прогноз оказывается хуже среднего значения test.

Проверенный исходный результат хранится в `results/regression_seed42.json` вместе
с версиями окружения. Тест сравнения качества относится только к этому небольшому
набору и seed; он не гарантирует улучшение на произвольных данных.

Попробуй объяснить разницу MAE и RMSE, затем добавь отдельный эксперимент с другим
`alpha`, оценивая его по CV внутри train. Уже просмотренный test не подходит для
дальнейшего подбора параметров и заявления о новой независимой оценке качества.
